VUEMesh

Privacy

Exactly what VUEMesh keeps, where, and for how long. This page describes the site at vuemesh.com. VUEMesh is open source (MIT), so anyone can run their own copy; a copy run by someone else is theirs, and so is what it keeps.

The short version
  • No cookies, no accounts, no ads, no trackers, no third-party analytics. There's nothing to accept.
  • Never your location. VUEMesh doesn't ask where you are, and there's no public list or map of events.
  • Your recordings stay on your devices. Video goes from device to device over your own network. Our server never receives it.
  • The server keeps an event's name and settings for 30 days, so devices can find each other, then deletes it by itself.
  • You can clear everything VUEMesh keeps in this browser with one button, below.

In this browser

VUEMesh is an app that runs in your browser, and it keeps its work there, on this device only, the way a document editor keeps files. None of this is a cookie and none of it is sent anywhere by itself. It's grouped here by what it's for; every key starts with vm_.

What this browser has now

Checking…

This removes every recording, edit, key and setting VUEMesh has in this browser, and the saved copy of the app. Export anything you want to keep first, from the home page. It can't be undone, and without its host key you can't run the studio for an event again.

On our server

The server is a small switchboard. It helps devices at an event find each other, then gets out of the way. It keeps:

  • Each event: its name, code, shape (landscape or portrait), settings, the Terms its people agreed to, a one-way hash of the host's key, when it was made, and when the studio was last open. Deleted automatically 30 days after it's made (12 hours for a show started at a kiosk), or sooner when the host deletes it.
  • Who's connected right now: a random ID for each device in the event, the name it joined with, and its role (camera, microphone, studio, TV). Used to pass the handshake between devices. Deleted within a day.
  • Anonymous counts for each day, which don't expire: events made and run, how many cameras, microphones and viewers joined, recordings made, hours of footage, live cut and streaming. So a phone that rejoins is counted once, the event holds a one-way code made from that phone's random camera ID, deleted with the event. The day's counts name no person, device, place or event. They may be shared, for example with partners or funders.
  • Anonymous page views: one count per page load, by page, with the site that linked to it, device type (phone, tablet, desktop), browser name, and country if the network provides it. A visitor is counted once a day using a salted hash of the day, the address and the browser, which can't be turned back into either and isn't kept with the counts. None of this is sent if your browser asks not to be tracked (Do Not Track or Global Privacy Control).

If you email us

Mail to info@vuemesh.com is received by Amazon's email service, checked for viruses and spam, and forwarded to the maintainer's inbox. A copy is kept encrypted on AWS for 30 days, then deleted automatically; the forwarding keeps a one-line record that a message was passed on (its ID, not its contents) for 14 days. Nobody else reads it, and the address isn't added to any list.

Recordings never go to the server. Film publishing (uploading a finished film for a watch page) exists in the code but is turned off on vuemesh.com. If it's ever turned on, it will be something a host chooses for a film, and this page will say what it keeps.

Other services your browser talks to

  • Amazon Web Services hosts the site, the server, and mail to info@. Like any host, it handles your requests and may keep its own short operational logs.
  • Google's STUN server (stun.l.google.com): when devices connect, each asks it for its own public address, so they can find a path to each other. It sees that request and nothing else; no video goes through it.
  • Google Fonts serves the Archivo typeface on some pages, so Google sees that your browser asked for a font. (Moving it onto our own server is on the list. Help welcome.)
  • Only when you set them up: a streaming service you stream to (YouTube, Twitch and the like), and Patreon or email if you follow those links.

Your choices

  • Delete or export a single event's recordings from the home page, or a phone's from My footage.
  • Clear everything with the button above, or with your browser's own "clear site data".
  • Turn on Do Not Track or Global Privacy Control and no page views are counted.
  • A host can delete an event from the server at any time from the studio; it deletes itself after 30 days anyway.
  • Run your own copy: it's MIT licensed, and your copy keeps only what you choose.

Changes and questions

If what VUEMesh keeps changes, this page changes with it, in the same release (it's in the public repository, so every change is visible). Questions: get in touch, or open an issue.
